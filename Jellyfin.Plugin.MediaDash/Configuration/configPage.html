MediaDash setup

waving_handWelcome

MediaDash looks after your library the way a librarian would: it spots duplicates, broken files, oversized encodes and unwanted language tracks, then fixes them safely on a schedule.

The next few screens step through each feature. Any of them can be turned off entirely — nothing is set in stone, everything here is also in Settings.

Dry-run is on by default, so nothing on disk changes until you decide it should.

video_libraryLibraries to scan

Only the libraries ticked here are scanned. Untick a library and MediaDash won't touch any file inside it. Leave everything ticked to include all your movie and TV libraries.

Confirms Jellyfin can read AND write the ticked libraries. Fixes fail silently if the underlying files aren't writable by the user Jellyfin runs as.

content_copyDuplicate copies

Finds the same movie or episode saved more than once and keeps just the best copy. "Best" is decided by the policy below.

play_disabledBroken files

Test-plays every file — start, middle, end — and flags anything that won't decode. Broken files are always re-checked at fix time before removal.

Test-plays three points in every file. Slower on first scan; results are cached for unchanged files. Turn off for a much faster header-only check.

compressOversized files

Flags files bigger than your quality ceiling. When fixed, they're re-encoded down; the original goes to the recycle bin.

Much faster, slightly larger files. Uses Jellyfin's configured accelerator (NVENC / QSV / AMF / VideoToolbox); falls back to software per-file if it fails.
Pick the card re-encodes should target when your server has more than one (typical: iGPU + dGPU). "Auto" follows Jellyfin's Playback → Hardware acceleration setting. Only NVENC / AMF honour this override; QSV / VideoToolbox fall back to Jellyfin's device.
Re-encoding HDR without proper color-space handling destroys metadata. Leave on unless you know you want to touch HDR content.

local_fire_departmentTranscode-heavy files

MediaDash reads Jellyfin's ffmpeg logs to spot files that transcoded on the fly (heavy CPU) or failed to transcode at all. A one-off targeted re-encode turns future plays into direct-play. Off by default because it acts on Jellyfin's own log directory, not your library — no risk until you flip it on.

compressTrickplay thumbnails

Jellyfin's scrub-bar preview thumbnails are stored as raw JPGs. Re-encoding to WebP typically halves the disk footprint. Only touches Jellyfin's own trickplay data folder — your library files are never modified. The .jpg extension is preserved so clients keep serving them unchanged.

translateLanguage cleanup

Removes audio and subtitle tracks you don't understand. A file's only remaining audio track is never removed, and tracks with no language tag are always kept.

Press Enter or comma to add each language. Empty leaves audio cleanup off.
Press Enter or comma to add each language. Empty leaves subtitle cleanup off.
Downloads from Jellyfin's configured subtitle providers. Providers (e.g. Open Subtitles) install as separate plugins from Dashboard → Plugins → Catalog; the API key lives on that plugin's page, not here.

albumMusic & audiobook covers

Music and audiobook folders often ship with every track carrying its own copy of the same album art. MediaDash can extract one shared cover.jpg per folder and optionally strip the duplicates from each audio file — roughly 500 KB saved per track. Only runs on Music / Audiobook libraries.

Off = extract cover.jpg only, audio files untouched. On = also remove the embedded cover from each track (originals recycled first). Bigger space win but every audio file gets a lossless remux.

drive_file_moveMedia sorter

Spots files in the wrong folder (a movie under TV, or a TV episode under Movies) and moves them where they belong. Set both target folders to turn the sorter on; leave either empty and it stays off.

Absolute path inside a Jellyfin library. Moves outside your libraries are refused.
Absolute path inside a Jellyfin library.
Items with Jellyfin's "Anime" genre tag go here instead of Movies / TV.
Music and audiobook files land here when misplaced.
EPUB / PDF / MOBI files land here when misplaced.
Metadata is what Jellyfin already scraped. Switch to the filename fallback if your files aren't correctly tagged (looks for SxxExx / NxN patterns).

descriptionBroken metadata sidecars

Corrupt .nfo files (zero-byte, malformed XML, unrecognised root element) stop Jellyfin from reading metadata. Deleting them is safe — Jellyfin re-fetches from your configured providers on the next library scan. Keep them in the recycle bin if you hand-curate NFOs.

gpp_badSuspicious executables

Walks every ticked library for .exe / .msi / .bat / .ps1 / .jar and other executable extensions that never belong in a media folder. Almost always malware bundled with a pirated release.

folder_deleteHousekeeping

Two low-risk cleanups: leftover orphan files (subtitle sidecars, trickplay folders, or Jellyfin metadata folders whose companion video is gone) and unused embedded fonts inside .ass subtitle files. Both are safe defaults — orphans go to the recycle bin, font trimming rewrites the .ass file in place.

Rewrites .ass sidecars with only the fonts your styles actually reference — a contents-only edit.

shieldSafety net

Two guardrails that keep every scan and fix reversible, plus how long the recycle bin keeps removed files before it purges them.

Fix runs only log what they would do; nothing is changed. Turn off later once you're happy with the plan shown in History.
Scheduled scans and fixes wait until nobody is watching anything and nobody has used Jellyfin for 15 minutes. Manual "Scan now" / "Run fixes now" always run immediately.
How long removed files are kept before they are permanently purged.

hourglass_bottomStale content

Optional: MediaDash can also list media that has sat on the server for a long time without anyone playing it. Off by default because "stale" is a personal call — surface the list only if you'd like a nudge to prune it.

Detect-only. MediaDash never deletes stale files automatically — the list shows on the Issues tab so you decide.
Nothing is flagged until the item has both been on the server this long AND not been played by anyone in that window. Default 365.

analyticsCommunity stats (optional)

MediaDash can send anonymous aggregate stats to a community board so everyone can see how much storage the plugin is reclaiming across all users. Tick the box below to opt in — either is fine for the plugin.

What's sent, per fix run: a month-rotated anonymous ID (SHA-256 of Jellyfin's SystemId + this year-month + a plugin-scoped salt — the same install produces the same ID inside a month so the backend can dedupe, but a fresh ID appears on the 1st of every month and can't be linked back to the previous one), your plugin version, your Jellyfin version, the current month, and cumulative counts of the fixes MediaDash has completed this month for every scanner (duplicates, broken files, oversized encodes, unwanted subtitles / audio, missing subtitles, misplaced files, stale content, corrupt artwork, suspicious executables, ungrouped media, large trickplay, subtitle fonts, orphaned debris, corrupt NFO, heavy / failed transcodes, embedded cover art) plus the total bytes freed.
What's never sent: your Jellyfin SystemId itself, file paths, filenames, library names, IP addresses, media titles, or anything that identifies you or your media. Nothing is stored on disk to derive the ID from — it's computed at report time and forgotten.
Change your mind any time in Settings → Safety. See docs/PRIVACY.md for the full list and the DB schema.
Aggregated numbers show up on the MediaDash GitHub page, refreshed monthly. Great for seeing collective impact.
