Doc drift: probe cache is skipped entirely when (size, mtime_utc) unchanged — so `probed_at_utc` never advances until the source file mtime actually changes. The doc claims a "touch" behaviour that does not exist.

Not a functional bug — the "content stable" invariant holds. Simply update E.2 to say "row untouched when file mtime unchanged".
