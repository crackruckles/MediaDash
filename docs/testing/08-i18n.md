## 08-B · Per-locale coverage

For each locale below: verify key count, key parity with English,
placeholder parity, no empty strings, sane character set, correct in UI.

### Common per-locale checklist

For a locale `LOC`:
1. `$loc = Get-Locale LOC`
2. `$loc.PSObject.Properties.Name.Count` should equal `$N` (or match
   documented gap list).
3. Every key present in `$en` present in `$loc` (or documented as
   deferred to fallback):
   ```powershell
   Compare-Object $en.PSObject.Properties.Name $loc.PSObject.Properties.Name
   ```
4. No value is empty or only whitespace:
   `$loc.PSObject.Properties | Where-Object { -not $_.Value.Trim() }` → empty.
5. Every `{tokenName}` in the English value present in the localized
   value.
6. In Jellyfin: switch dashboard language, load MediaDash → primary
   labels render in `LOC`, no visible "??".
