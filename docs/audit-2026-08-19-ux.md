# MediaDash UX Audit — 2026-08-19

Independent end-to-end user experience audit ahead of 1.0.

Status legend: `[ ]` open, `[x]` fixed, `[!]` disputed / not-a-bug, `[~]` in progress.

---

## Critical (block 1.0)

- [x] **UX-C1. Wizard step translations never apply for any non-English locale.**
  JS guard checks `i18n.wizSteps.length === WIZ_STEP_LABELS.length`; `WIZ_STEP_LABELS` has 17 entries, `en.json` has 16, every non-English locale has 9. Guard never passes — all users see English wizard regardless of locale.
  **Fix:** normalize entry count (add missing 17th to en.json, backfill all locales) OR relax guard to `>=` with fallback for out-of-range.

- [x] **UX-C2. Retention slider silent data loss.**
  Wizard input is `min=1 max=365`; Settings tab is `min=1 max=90`. User sets 120 in wizard → later opens Settings, saves → 120 truncated to 90 with no warning.
  **Fix:** change Settings `<input type="range" max="365">` to match the wizard.

- [x] **UX-C3. Version reports "0.0.0.0" → update banner fires on every load.**
  `/MediaDash/Environment` returns `PluginVersion` sourced from `_appHost.ApplicationVersionString` which is Jellyfin's server version, not the plugin's. In dev this returns 0.0.0.0.
  **Fix:** source from `typeof(Plugin).Assembly.GetName().Version`.

- [x] **UX-C4. 5 IssueType labels/descriptions untranslated in every locale.**
  `HeavyTranscode`, `OrphanedDebris`, `LargeTrickplay`, `EmbeddedCoverArt`, `FailedTranscode` are absent from `en.json` `types` dict AND every locale file. JS falls back to hardcoded English STR defaults.
  **Fix:** add 5 type objects (title/description/action) to en.json and all 8 locale files.

- [x] **UX-C5. "Recycle bin" tab hardcoded English.**
  Every other tab uses `<span data-i18n="tab.X">`; recycle bin uses plain `<span>Recycle bin</span>`. No `tab.recyclebin` key exists.
  **Fix:** add `data-i18n="tab.recyclebin"` + key in en.json and locales.

## High

- [ ] **UX-H1. 35 STR keys never translatable — present in JS defaults but absent from en.json.**
  Includes: bin full banners, restore-overwrite prompt, context-menu labels, clearAll, langFilter*, lifetimeSaved, pagination "page", plus all 16 issue-type title/description/action strings.
  **Fix:** add all 35 to en.json (translators can then fill in locale files as follow-up).

- [ ] **UX-H2. Pagination controls hardcoded (Prev/Next/Cancel/Save changes).**
  No `data-i18n` attributes; keys don't exist.
  **Fix:** add `data-i18n` + keys.

- [x] **UX-H3. No viewport meta tag → broken layout on mobile/tablet.**
  Jellyfin admin from phone is a common pattern; without `viewport` the UI renders as a scaled-down desktop page requiring pinch-zoom.
  **Fix:** add `<meta name="viewport" content="width=device-width, initial-scale=1">` to `<head>`.

- [ ] **UX-H4. 15 `STR.key || "English fallback"` patterns bypass i18n pipeline.**
  Because STR is populated from JS defaults first (which contain the "fallback"), the `||` branch never fires but the string still can't be translated.
  **Fix:** remove the `|| "..."` fallback once en.json has the keys (covered by H1).

## Medium

- [!] **UX-M1. `color-mix()` on old browsers.**
  Firefox <113 / Chrome <111 / Safari <16.2. Modern browsers are ubiquitous now on Jellyfin admin surfaces; the graceful degradation (flat colors) is acceptable for 1.0.

- [x] **UX-M2. `:focus` should be `:focus-visible`.**
  Focus rings appear on mouse-click, which reads as a bug. One-token change per ruleset.
  **Fix:** replace `:focus` with `:focus-visible` in CSS where the ring is for keyboard nav.

- [!] **UX-M3. Google Fonts + Material Symbols from CDN.**
  Air-gapped Jellyfin admins see raw ligature text ("home", "settings") instead of icons. Real problem for air-gapped installs. Recommend bundling for 1.0.1 — non-trivial change; deferring.

- [!] **UX-M4. "Report an issue" button copies clipboard silently + opens URL.**
  User doesn't know clipboard was written.
  **Fix:** add a brief inline "Copied!" state on the button.

- [!] **UX-M5. Tab tooltip/title strings hardcoded English.** Minor. Deferring to 1.0.1.

- [!] **UX-M6. Overview buttons briefly show English before poll completes.** First-poll race; harmless. Deferring.

## Low

- [!] **UX-L1. Ignore-by-extension/folder/type has no un-ignore hint.** Manage in Settings.
- [!] **UX-L2. "No history" tooltip is technical.**
- [!] **UX-L3. Errors tab empty state is a blank container.**
- [!] **UX-L4. 0 B files display as "0 B" — technically correct.**
- [!] **UX-L5. Scan ETA "calculating…" persists on large libraries.**

## Strengths noted (preserve as-is)

Destructive-action confirmation gating, force-restore conflict handling, fingerprint-based DOM diff on polling, SMART health display, library breakdown charts, pause-during-playback with escape hatch, post-upgrade migration offer, per-version update banner dismissal, LibraryGuard on all Files ops, cross-volume recycle bin warning.
