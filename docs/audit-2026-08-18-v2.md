# MediaDash Bug Audit — 2026-08-18 (second pass)

Independent deep-dive audit by a fresh Claude agent with no prior context. Read-only.

Status legend: `[ ]` open, `[x]` fixed, `[~]` in progress, `[!]` disputed / not-a-bug on closer look.

---

## High

- [x] **H1v2. `Data/MediaDashDb.cs:562-596` — `RelocateIssuePaths` case-sensitive on Windows paths.**
  SUBSTR match uses byte-exact equality. On Windows, if the stored path and the fixer's post-move path differ only in casing, sibling issues never re-point and next fix run fails with "no longer exists".
  **Fix:** NOCASE collation or `LOWER(path) = LOWER(@old)` (and the sentinel comparisons too).

- [x] **H2v2. `Fixers/PlayabilityFixer.cs:127-129` — `size-truncated` re-verify checks only duration.**
  Truncated files still report a positive header duration; the size-vs-bitrate check that flagged them isn't re-run. Result: truncated files never get deleted, the issue re-detects forever.
  **Fix:** mirror scanner's `actualSize < expectedBytes * 0.6` check with `probe.Format?.BitRate` and `FileInfo.Length`.

- [x] **H3v2. `Fixers/TranscodeFixer.cs:194-197` — Swap sidecar name isn't unique.**
  Hot-reload leaves an old ffmpeg past the 5-min sweep window; a fresh fix on the same target collides on `<file>.mediadash.swap.<ext>`. Either the fresh run's `File.Delete(swapPath)` clobbers the orphan's about-to-commit output, or the `File.Move` races the orphan's own move — truncated file at target, or fresh fix fails with a diagnostic pointing at someone else's sidecar.
  **Fix:** per-run GUID suffix on swap name.

- [x] **H4v2. `Scanners/LanguageHelper.cs:58-75` — ISO 639-1 tags don't fold to ISO 639-2.**
  `"en"` audio track against allowed `["eng"]` normalises to different strings, gets flagged for **removal**. TrackFixer removes it because a Spanish track is present ("last audio" invariant passes with keep.Count == 1).
  **Fix:** extend `BibliographicToTerminological` with 2→3 letter map, or use `CultureInfo` lookups.

- [x] **H5v2. `Data/MediaDashDb.cs:619-630` — `GetIssue(id)` full-scans the whole issues table.**
  Loads every issue via `GetIssues()`, filters in C#. Every Approve/Dismiss/Restore call stalls at scale.
  **Fix:** targeted `WHERE id=@id` SELECT, same shape as `GetIssueStatus`.

## Medium

- [x] **M1v2. `Api/FileBrowserController.cs:629-651` — `CopyDirectory` StackOverflow on symlink cycle.**
  No reparse-point filter, no seen set. `/MediaDash/Files/Copy` on a tree with a symlink loop terminates the Jellyfin process.
  **Fix:** `EnumerationOptions { AttributesToSkip = ReparsePoint, ... }` or a depth cap + visited set.

- [x] **M2v2. `Fixers/LibraryGuard.cs:111-157` — `SweepOrphanSidecars` no reparse skip.**
  Symlink loop under a library root spins CPU until thread pool starves at every FixTask end.
  **Fix:** `EnumerationOptions { RecurseSubdirectories = true, AttributesToSkip = ReparsePoint, IgnoreInaccessible = true }`.

- [x] **M3v2. `Fixers/PostUpgradeCleanup.cs:50` — Wrong trickplay root path.**
  `Path.Combine(_appPaths.DataPath, "trickplay")` doesn't match Jellyfin's actual trickplay layout (library-adjacent `*-trickplay` folders or metadata-side). Cleanup silently no-ops, marks itself done permanently.
  **Fix:** scan library roots for `*-trickplay` folders (reuse `OrphanCleanupScanner.SiblingSuffix` logic).

- [x] **M4v2. `Fixers/MediaSorterFixer.cs:97-99` — `Path.GetPathRoot` always `/` on Linux.**
  Cross-volume free-space pre-check never fires on Linux; File.Move to a full target drive fails mid-copy with truncated file left at target.
  **Fix:** reuse `RecycleBin.FindDriveForPath` (already handles cross-platform mount detection).

- [x] **M5v2. `Fixers/TrackFixer.cs:291-296` — Self-referential subtitle guard uses raw string compare.**
  No `Path.GetFullPath` normalisation. Legacy relative-path issue rows slip through; the just-remuxed video gets recycled and its size counted as "freed".
  **Fix:** normalise both paths via `Path.GetFullPath` before comparison.

- [x] **M6v2. `Probing/SmartHealthProbe.cs:361-366` — `df` argument built as single string.**
  Spaces in mount name tokenize into two args, df errors to stderr, SMART shows Unknown forever.
  **Fix:** `ProcessStartInfo.ArgumentList.Add(...)` instead of the command line string.

- [x] **M7v2. `Fixers/FfmpegExecutor.cs:222-232` — `TryKill` doesn't await exit.**
  Finally races OS-level ffmpeg teardown; on Windows reliably throws "file in use" on the temp delete.
  **Fix:** `await process.WaitForExitAsync` with bounded token after TryKill.

- [x] **M8v2. `Api/FileBrowserController.cs:614-627` — `IsSimpleName` misses Windows reserved names.**
  `CON`, `PRN`, `AUX`, `NUL`, `COM1-9`, `LPT1-9`, trailing dot/space all sneak through. CreateDirectory silently fails or aliases to a device.
  **Fix:** explicit denylist + reject trailing dot/space.

- [x] **M9v2. `Api/MediaDashController.cs:579` — `RestoreFromHistory` pulls full history to find one row.**
  Uses `_db.GetHistory().FirstOrDefault(h => h.Id == id)` when `GetHistoryEntry(id)` exists five lines away.
  **Fix:** call the existing helper.

- [x] **M10v2. `Api/MediaDashController.cs:1118-1132` — `RestoreOptimizedCopy` skips LibraryGuard.**
  `entry.Path` from a legacy history row (older MediaDash version, hand-edited DB) can point outside any library; the force=true path ships it to the recycle bin.
  **Fix:** assert `_libraryGuard.IsInsideLibrary(entry.Path)` before both `MoveToBin` and `Restore`.
