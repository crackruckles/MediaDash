# MediaDash Bug Audit — 2026-08-18

Independent audit by a Claude agent with no prior project context. Read-only.
Findings ranked by severity. Deeper analysis to follow — see `audit-2026-08-18-deep.md`.

Status legend: `[ ]` open, `[x]` fixed, `[~]` in progress, `[!]` disputed / need more info.

---

## High

- [x] **H1. `ScheduledTasks/FixTask.cs:21-35` — `FixableTypes` missing 5 issue types.**
  MissingSubtitles, Ungrouped, HeavyTranscode, FailedTranscode, EmbeddedCoverArt are absent from the array. The auto-queue loop at line 122 iterates `FixableTypes`, so setting `FixMode.Automatic` for any of these is silently ignored. Detected issues sit in `Detected` forever unless manually approved.
  **Fix:** add the 5 missing `IssueType` values. Keep `Stale` omitted (no fixer).

- [x] **H2. `Fixers/PlayabilityFixer.cs:115-118` — audio items deleted on re-verify.**
  `IsStillBrokenAsync` treats "no video stream" as still-broken without checking item kind. An audio-kind item flagged `no-audio` that has since gained real audio is deleted anyway.
  **Repro:** Audio/AudioBook item flagged with reason `no-audio`; user replaces with a proper audio file; fixer probes, sees no video stream (correct for audio), returns true, recycles the good file.
  **Fix:** mirror the scanner's `IsAudioKind` check — audio-kind items require missing audio stream, not missing video stream.

- [x] **H3. `Fixers/RecycleBin.cs:100-119` — `FindDriveForPath` prefix match lacks separator boundary.**
  On Linux, mount `/mnt/media` will match path `/mnt/media-backup/...` because `DriveInfo.RootDirectory.FullName` has no trailing slash. Wrong drive is picked → cross-volume detection, free-space checks, and Overview drive tagging all use wrong drive.
  **Fix:** after `StartsWith`, require next char to be a directory separator OR full path == root.

- [x] **H4. `Fixers/ArtworkFixer.cs:39` — same prefix-without-boundary flaw on metadata root.**
  The "defense in depth" library-root check uses raw `StartsWith`; `/data/metadata-evil/foo.jpg` passes when `InternalMetadataPath` is `/data/metadata`.
  **Fix:** use `LibraryGuard.IsUnder`-style comparison (canonicalize + require separator boundary).

## Medium

- [x] **M1. `Configuration/PluginConfiguration.cs:171` — `MaxConcurrentTranscodes` is dead config.**
  User-facing setting never read anywhere; fixes always run single-threaded.
  **Fix:** either delete the field + UI, or wire it into `FixTask`'s loop with a `SemaphoreSlim`.

- [x] **M2. `Fixers/EmbeddedCoverArtFixer.cs:85-86` — cover filename allows path traversal.**
  `config.EmbeddedCoverFilename` is `Path.Combine`d without validation. `"../evil.jpg"` writes outside the target folder; absolute paths write anywhere. Admin-privileged, but config XML restores from untrusted sources are a real vector.
  **Fix:** reject names with separators or `..`; or combine then `IsUnder(folder)` check.

- [x] **M3. `Fixers/LibraryGuard.cs:33-39` — `IsInsideLibrary` doesn't resolve symlinks.**
  `Path.GetFullPath` canonicalizes lexically only. Symlink `/movies/back -> /etc` inside a library lets `/movies/back/passwd` pass the guard; subsequent `File.Delete`/`Move` follows the link. Requires local write access to plant the link; escalation vector on hostile multi-tenant hosts.
  **Fix:** use `File.ResolveLinkTarget` / reject when resolved final target escapes the library root, or refuse any path where an ancestor is a link outside the library.

- [x] **M4. `Fixers/RecycleBin.cs:55-58` — `MoveToBin` timestamp collision.**
  Two files recycled in the same millisecond with the same basename collide on the target `yyyyMMdd-HHmmss-fff` folder. Second `File.Move` throws IOException, recorded as false failure; worse, races may put both into the same folder.
  **Fix:** append `Guid.NewGuid().ToString("N")[..8]` or an `Interlocked.Increment` counter to the folder name.

- [x] **M5. `Api/Diagnostics.cs:64-70` — `Recent()` returns live entry references.**
  `Record()` mutates entries in place (LastAtUtc / Count) during dedup after `Recent()` has returned. Concurrent read + write while controller serializes → torn JSON.
  **Fix:** replace entry on dedup rather than mutate, or deep-copy under the lock inside `Recent()`.

## Low

- [x] **L1. `Probing/SmartHealthProbe.cs:140` — smartctl pipe deadlock >64KB.**
  `ReadToEnd()` after `WaitForExit`. Enterprise SSDs with large SMART attribute logs produce `-j` output >64KB; child blocks on write, 3s timeout kills it. Degrades to `Unknown` status.
  **Fix:** start `ReadToEndAsync` before `WaitForExit` (mirror ffprobe pattern).

- [x] **L2. `Api/MediaDashController.cs:967-986` — `EmptyRecycleBin` TOCTOU on IsRunning gate.**
  Check-then-launch not atomic. Two POSTs in the same millisecond both see `IsRunning=false`, both launch `EmptyAll`. Concurrent state races, `Directory.Delete` throws in one.
  **Fix:** push guard into `RecycleBin.EmptyAll` with `Interlocked.CompareExchange`, or class-level lock.

- [x] **L3. `Fixers/RecycleBin.cs:155` — `GetContents` throws on locked subfolder.**
  `Directory.EnumerateFiles` with `SearchOption.AllDirectories` throws `UnauthorizedAccessException` mid-iteration; only per-file `FileInfo` is guarded. One unreadable folder aborts the whole size scan → Overview drive card errors out.
  **Fix:** wrap the foreach; or manual queue that swallows per-directory access errors.

- [x] **L4. `Fixers/FfmpegExecutor.cs:257-283` — stale-ffmpeg sweep can kill live siblings.**
  `SweepStaleMediaDashFfmpegs` matches by sidecar suffix without considering process age. No current parallel ffmpeg spawner, but any future parallel scanner would be killed.
  **Fix:** only kill processes with `StartTime` older than N minutes.

- [x] **L5. `Fixers/TranscodeFixer.cs:108-109, 212` — target-exists race with re-download.**
  When `targetContainer` matches source extension, `targetPath == issue.Path`. If Sonarr/Radarr re-fetches between disposal and `File.Move`, Move throws while `originalDisposed=true`, mis-attributed to "swap preserved".
  **Fix:** pre-`File.Move`, check `File.Exists(targetPath)` and treat as distinct error path.

---

## Clean areas noted

FfprobeService, TrackFixer core swap, DuplicateFixer, SQLite migration path, RecycleBin swap-and-preserve invariant, Diagnostics ring buffer bounding. Safety architecture (LibraryGuard everywhere, dry-run defaults, re-verification at fix time) holds up aside from the specific gaps above.

# Deep-dive pass — same day

Second independent agent. All prior findings re-verified in code; new bugs added below.

## Verdicts on prior findings

- **H1** CONFIRM. DI has all fixers registered; bug is purely in the `FixableTypes` array.
- **H2** CONFIRM + escalate. `IsStillBrokenAsync` also treats `probe.Format.Duration <= 0` as broken — many valid audio files (opus, some m4b) report duration on the stream not the format, so audio items get recycled even when playable.
- **H3** CONFIRM. Affects `MediaDashController.GetStatus`, `ComputeRecycleBinCrossVolume`, `TranscodeFixer` free-space check, and Overview drive tagging.
- **H4** CONFIRM. The "defense in depth" comment is a lie — `ArtworkScanner.cs:64` has the same raw-`StartsWith` flaw.
- **M1** CONFIRM. `FixTask.cs:178` runs a plain `for` loop; no semaphore anywhere.
- **M2** CONFIRM. Sole path-traversal sink from config.
- **M3** CONFIRM. Windows equivalent: NTFS junction / reparse point. `SweepOrphanSidecars` (`LibraryGuard.cs:66`) sets `AttributesToSkip = ReparsePoint` in one place only — `IsInsideLibrary` doesn't.
- **M4** CONFIRM. Also triggerable from concurrent Delete via FileBrowser + a fix run + `RecycleBin.RestoreOptimizedCopy` (`MediaDashController.cs:1127`).
- **M5** CONFIRM. `Recent()` returns `Entries.ToList()` — new list, live refs. Concurrent `Record()` mutates `Count`/`LastAtUtc` during serialization.
- **L1** CONFIRM. `stderr` also isn't drained — a smartctl warning on stderr deadlocks too.
- **L2** CONFIRM.
- **L3** CONFIRM. Sibling `ListContents` at line 190 uses top-level `GetDirectories` + per-subfolder `EnumerateFiles` and is guarded — only `GetContents` at 155 isn't.
- **L4** REFINE. Additional concrete trigger: `TrickplayOptimizeFixer.ConvertOneAsync` writes `<jpg>.mediadash.tmp` sidecars (line 209). If a track/transcode fixer runs concurrently with trickplay, the sweep matches the trickplay ffmpeg by cmdline substring `mediadash.tmp` and kills it. Also triggerable if the user manually re-triggers Fix during a running fix.
- **L5** CONFIRM + extra: the thrown `IOException` propagates up to `FixTask`'s generic Exception handler at line 311, which writes only a diagnostic and **no History row**. User loses the audit trail entirely.

## Critical

- [x] **C1. `Fixers/RecycleBin.cs:387-398` — `MoveAcrossVolumes` copy-then-delete has NO size verification.**
  On cross-volume move, `File.Copy(source, target)` then `File.Delete(source)` — if the target volume experiences truncated write (disk fills, USB unmount, NFS drop, swallowed writeback error), the source is gone and the recycle-bin copy is corrupt. `FileBrowserController.CrossDeviceMove` (line 655) explicitly checks `copiedInfo.Length != sourceInfo.Length` before removing source — RecycleBin's own implementation skips it. Every fixer using recycle-bin disposal is vulnerable when the bin sits on a different volume from the media (common config).
  **Fix:** mirror `FileBrowserController.CrossDeviceMove`'s size verification; consolidate into a single helper.

- [x] **C2. `Fixers/OrphanCleanupFixer.cs:159` — local `IsUnder` uses `OrdinalIgnoreCase` unconditionally.**
  `LibraryGuard.IsUnder` correctly picks Ordinal on Linux; this local copy hardcodes case-insensitive. On case-sensitive filesystems, any environment where the `metadata` directory case doesn't match the hard-coded candidate lets a crafted path pass the safety gate.
  **Fix:** delete the local copy, use `LibraryGuard.IsUnder`.

## High (new)

- [x] **NH1. `Api/FileBrowserController.cs:472-517` — Upload temp file allows path collision + orphan disk consumption.**
  Temp path is `parent/<name>.mediadash.upload.tmp`. `IsSimpleName` allows names ending in `.mediadash.upload.tmp`, colliding with a legitimate concurrent upload's temp. On failure/cancel, catch deletes the temp — can delete the OTHER upload's file. If `File.Delete` in the catch throws, tempPath is left on disk indefinitely; no orphan sweep pattern covers `mediadash.upload.tmp`.
  **Fix:** (a) per-request GUID in tempPath, (b) add `mediadash.upload.tmp` to `LibraryGuard.SidecarPatterns`.

- [x] **NH2. Ffmpeg orphan sweep misses `strip` and `swap` markers.**
  `LibraryGuard.SidecarPatterns` (line 15) and `FfmpegExecutor.SweepStaleMediaDashFfmpegs` (line 257-258) only match `mediadash.tmp*` / `mediadash.new*`. But `EmbeddedCoverArtFixer` creates `strip` sidecars (line 261-262) and `TrackFixer`/`TranscodeFixer` create `swap` sidecars. A SIGKILL / container restart during a strip leaves `<audio>.mediadash.strip.<ext>` on disk forever.
  **Fix:** extend sidecar patterns and sweep to include `strip`, `swap`; or unify under a single marker prefix.

- [x] **NH3. `Data/MediaDashDb.cs:552-575` — `RelocateIssuePaths` breaks on trailing separators.**
  On Windows, DB paths use `\`. The query hardcodes both `/` and `\` boundary sentinels, but if the caller passes `oldPath` with a trailing separator, the boundary duplicates (e.g. `D:\Movies\` + `\`) and the prefix match silently misses. Some fixers `TrimEndingDirectorySeparator`, some don't.
  **Trigger:** a move-style fixer producing a trailing-separator path; sibling issues aren't re-pointed and fail "no longer exists" on next fix run.
  **Fix:** normalize `oldPath`/`newPath` (`TrimEndingDirectorySeparator`) on RelocateIssuePaths entry.

## Medium (new)

- [x] **NM1. `Fixers/RecycleBin.cs:130-140` — `Restore` uses the same unverified `MoveAcrossVolumes`.**
  Cross-volume restore + destination fills up during copy → recycle-bin copy is deleted first, partial destination left behind. The file the user *asked* to protect is lost.
  **Fix:** same as C1.

- [x] **NM2. `Api/Diagnostics.cs:23-59` — Truncated messages dedup incorrectly.**
  `Record` truncates at 800 chars, then dedup compares the truncated form. Long ffprobe errors that share the truncation prefix (last-N-lines pattern from `TranscodeFixer.Truncate` at line 552) get collapsed into one entry; user sees count=42 thinking one repeating failure when actually 42 different ones.
  **Fix:** hash the pre-truncation message; compare hashes for dedup.

- [x] **NM3. `Fixers/FfmpegExecutor.cs:194-207` — `IsProgressKeyValueLine` filter swallows real errors.**
  Filter includes `stream_` prefix (line 206), matching legitimate error lines like `stream_0_0: audio stream missing`. Also filters based on progress-key prefix regardless of whether the line is actually a `key=value` progress row. On non-zero ffmpeg exit, `stderrTail` may be empty; user sees only exit code.
  **Fix:** only filter when `reportProgress` is on AND line matches full `key=value` pattern; never filter `stream_` prefix.

- [x] **NM4. `Fixers/AssSubtitleFile.cs:159` — no size cap on `.ass` parse.**
  `File.ReadAllBytes` loads entire file into memory; a 2GB corrupt/malicious `.ass` OOMs the plugin.
  **Fix:** cap via `FileInfo.Length` (100 MB is orders of magnitude beyond any real .ass).

- [!] **NM5. `Fixers/TrickplayOptimizeFixer.cs:170-193` — trickplay data-root check breaks on non-standard DataPath.**
  `Path.Combine(_appPaths.DataPath, "trickplay")` is passed to `LibraryGuard.IsUnder` without canonicalization. If DataPath is a UNC / has `.` segments / mapped drive, canonicalization mismatch forces every trickplay fix through the media-folder branch, which then requires the folder to be inside a library. Result: no trickplay fix ever succeeds.
  **Fix:** `Path.GetFullPath(dataRoot)` before passing to `IsUnder`.

- [x] **NM6. `Scanners/DuplicateScanner.cs:175` — potential NRE on `Path.GetFileName(null)`.**
  When provider IDs are missing, group key uses filename. Items with null `Path` (merged alternate versions, some virtual items) NRE and abort the scanner mid-run.
  **Fix:** `NormalizeName(Path.GetFileName(movie.Path) ?? string.Empty)`.

- [x] **NM7. `Fixers/MediaSorterFixer.cs:135` — `File.Move` without overwrite; TOCTOU + no History row on IOException.**
  Between `File.Exists(targetPath)` check at line 90 and this Move, Sonarr / manual copy can create target. IOException "already exists" doesn't match `IsOutOfSpace`, propagates to `FixTask`'s generic handler which writes no History row.
  **Fix:** catch generic IOException and translate to `FixResult.Fail` explicitly.

- [x] **NM8. `Fixers/MissingSubtitleFixer.cs:65-73` — network stall aborts entire fix run.**
  Catches `InvalidOperationException` / `HttpRequestException` but not `TaskCanceledException` from provider network timeout. Uncaught, it bubbles to FixTask and aborts the run.
  **Fix:** catch `TaskCanceledException` distinctly — if outer token not cancelled, treat as network error and continue.

## Low (new)

- [x] **NL1. `Fixers/RecycleBin.cs:180-215` — `ListContents` uses filesystem creation time.**
  `Directory.GetCreationTimeUtc(dir)` returns local-time-coerced-to-UTC on FAT32/exFAT. Cross-timezone recycles are off by TZ offset, misordering the "newest first" listing.
  **Fix:** parse the folder-name timestamp for ordering rather than filesystem metadata.

- [x] **NL2. `Data/MediaDashDb.cs:848-853` — no try/catch on `SqliteConnection.Open()`.**
  Concurrent SQLite file lock (backup tool, virus scanner, WAL checkpoint) throws out of every public method → API 500 with no diagnostic trail.
  **Fix:** wrap `Open()` in try/catch that records to Diagnostics, or move to a single long-lived shared connection.

- [x] **NL3. `Api/FileBrowserController.cs:646-653` — `IsCrossDeviceError` sniffs error message string.**
  Localized on non-English hosts. Real EXDEV fails the check, gets rethrown as non-cross-device IOException → 500 instead of copy-fallback.
  **Fix:** check HResult (`ex.HResult & 0xFFFF == 17` Windows, `== 18` Linux), same pattern as `MediaSorterFixer.IsOutOfSpace`.

- [x] **NL4. `Scanners/OrphanCleanupScanner.cs:255-297` — `EnumerateFiles(..., AllDirectories)` unguarded.**
  Same shape as L3. One unreadable subfolder aborts the whole subtitle-orphan pass for that root.
  **Fix:** use `EnumerationOptions { IgnoreInaccessible = true, RecurseSubdirectories = true }` (already used by `SuspiciousFileScanner`).

- [!] **NL5. `Fixers/SubtitleFontFixer.cs:159` — locked-file rewrite loses pending changes.**
  If the `.ass` file is currently locked (Jellyfin live-transcoding), Move throws and finally deletes tmp; no History row.
  **Fix:** no reliable Jellyfin API to detect playback lock — document as a known limitation, or defer subtitle rewrites via a scheduled task rather than during active playback windows.

- [x] **NL6. `Analytics/AnalyticsReporter.cs:102-107` — analytics failures logged only at Debug.**
  Backend schema drift silently breaks analytics; no user-visible signal.
  **Fix:** log at Warning at least once per session on non-2xx.

- [!] **NL7. `Probing/FfprobeService.cs:57` — mtime-based cache key loses precision on FAT-family filesystems.**
  Two edits within a 2s window collide on FAT/exFAT; the second serves stale probe data. Minor.
  **Fix:** current behaviour probably a wash; acceptable to leave.

- [x] **NL8. `Api/MediaDashController.cs:472-502` — `BulkUpdateIssues` inline-binds unbounded parameters.**
  SQLite default limit 999; "Approve all shown" on a fresh install with 5000+ duplicates throws SqliteException → 500.
  **Fix:** batch in chunks of 500 inside `BulkUpdateOpenIssueStatus`, or use a temp table.

- [x] **NL9. `Api/FileBrowserController.cs:157-169` — `VirtualFolders` enumerated without snapshot.**
  Concurrent library-add via Jellyfin dashboard while FileBrowser is being used → enumeration-modified exception → 500.
  **Fix:** `.ToList()` snapshot before iterating.

## Second-pass clean-area notes

- **TrackFixer swap logic** — three-step temp→swap→dispose→final-move defended correctly; guards preserve sidecar. Sibling issue is only the orphan-sweep pattern gap (NH2).
- **DuplicateFixer** — re-verify checks solid. Minor defense-in-depth: no library-guard on `keeperPath`; not exploitable today (DetailsJson is scanner-written) but would harden against future callers.
- **FfprobeService** — async pattern correct (stdout task before WaitForExit).
- **SQLite migrations** — v1→v3 idempotent, guarded; transactional multi-row ops correct.
- **No `async void`, no `.Result`, no `.Wait()`** in any read files. Only fire-and-forget `Task.Run` is `MediaDashController.cs:972`, gated by IsRunning (with L2 TOCTOU).
- **No catastrophic regex backtracking** in `AssSubtitleFile`, `MediaSorterScanner`, `SystemStats`, `FfmpegExecutor`.
- **Culture sensitivity** — `LibraryGuard.IsUnder` branches on OS correctly; `OrphanCleanupFixer`'s local copy does not (see C2).
